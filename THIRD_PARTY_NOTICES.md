# Third-party software and corresponding source

The Android wrapper is MIT-licensed. The packaged AIStudio2API core is an unmodified upstream v0.3.0 executable, SHA-256 pinned in build.py. AIStudio2API's own code is MIT-licensed; its dependencies retain their own licenses, including LGPL and MPL components. The core must not be described as exclusively MIT-licensed.

The APK includes dependency notices under assets/licenses/, assets/DEPENDENCIES.json and Mozilla's consolidated license file assets/Mozilla-license.html. Root license files for this wrapper and upstream are included in assets/ as well.

Each prerelease distributing an APK must also provide the matching `AIS2A-Android-0.1.0-alpha-core-sources.zip` generated by prepare_notices.py. It contains the exact upstream core source archive, exact checksum-verified LGPL Go library source archives, the complete dependency inventory, and build instructions. Remaining permissively licensed dependency sources are restored with go mod download and verified by the supplied go.sum. The LGPL library code can be modified and the core rebuilt and replaced; the wrapper communicates with the core over loopback HTTP and runs it as a separate process.

Go dependency source inventories and hashes are available in assets/DEPENDENCIES.json after running prepare_notices.py. The build verifies each module archive against the core's go.sum. Libraries used only by other upstream platforms may be included conservatively in the inventory.

No additional restriction on modifying or reverse engineering the LGPL components for debugging such modifications is imposed by this project. The Android wrapper source, build script and signing procedure are published alongside the core source bundle; users can build and sign a replacement APK with their own key.
